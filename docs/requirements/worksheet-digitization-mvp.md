# 试卷图片整理 MVP 需求

## 目标

教师可在电脑或手机浏览器中导入 1–20 张试卷照片，完成方向、纸张边界、透视和灰度文字增强，必要时手动擦除或恢复局部内容，最终得到顺序正确、适合学生查看和 A4 打印的 PDF。

电子版中的每页仍是一张图片，不是可编辑、可搜索或可复制文字的文档。

## 范围

### 包含

- 无需登录的桌面 Chrome/Edge、Android Chrome 和 iOS Safari Web 应用。
- JPG、PNG、WebP、HEIC、HEIF 批量导入、拍照、校验、排序、删除和失败重试。
- 本地方向识别、纸张边界检测、透视校正、手动旋转和四角调整。
- 局部光照归一化、灰度转换和保守文字增强。
- 移动、缩放、白色擦除、恢复、撤销和重做。
- 统一 A4 竖版灰度 PDF，支持三档清晰度和三档页边距。
- 浏览器本地 24 小时任务恢复、主动清空和过期删除。

### 非目标

- 自动手写识别、自动擦除、自动水印移除或待复核遮罩。
- OCR、公式识别、可搜索 PDF、Word 导出或题目结构化。
- 账号、云同步、历史任务、分享链接或服务端图片处理。
- 自动重建被手写内容完全遮挡的印刷内容。

## 功能需求

| ID | 需求 | 验证方式 |
| --- | --- | --- |
| FR-1 | 一次接受 1–20 张支持格式图片；单张不超过 20 MB、4000 万像素；不合格文件逐个提示且不影响合格文件。 | 文件单测；混合上传 E2E |
| FR-2 | 每张图片成为独立页面并保持选择顺序；支持始终可见的上移、下移和删除操作。 | 排序 E2E |
| FR-3 | 高置信度方向结果自动应用；低置信度不强制旋转并提示用户确认。 | 四方向样张评测 |
| FR-4 | 高置信度纸张边界执行透视校正；低置信度保留整图；用户可拖动四角后重新处理。 | 几何样张与交互测试 |
| FR-5 | 输出进行局部光照归一化和灰度增强，不使用硬二值化，不丢失公式、表格线和插图细节。 | 像素评测与人工检查 |
| FR-6 | 编辑器支持移动、缩放、擦除、恢复、撤销和重做；缩放不改变笔画实际落点。 | 桌面/手机 E2E |
| FR-7 | 手机支持相机和相册；HEIC/HEIF 原生解码失败时使用按需本地解码器。 | HEIC 与移动端测试 |
| FR-8 | 页面处理在共享 Worker 中串行执行；一页取消或失败不丢失其他页面。 | Worker 单测；批处理 E2E |
| FR-9 | PDF 固定 A4 竖版、灰度输出，页面按比例居中且顺序一致；支持清晰/标准/小文件和 6/12/18 mm 页边距。 | PDF 页数与版式测试 |
| FR-10 | 任务刷新后可在 24 小时内恢复；v2 任务从擦除前 `enhanced` 基线迁移，不带入旧自动擦除结果。 | IndexedDB 迁移测试 |

## 质量属性

- **隐私**：图片、编辑结果和 PDF 全部在浏览器本地处理，不调用外部 OCR 或图像 API。
- **性能**：约 12 MP 首张缩略图在 3 秒内出现；处理期间界面保持可交互；20 页任务串行处理并及时释放中间位图。
- **输出**：清晰档优先打印可读性；小文件档仍须保证正文在 100% 缩放下可辨。
- **可访问性**：除画布绘制外，上传、排序、旋转、裁边、撤销、重做和导出均有可聚焦控件和可读名称。
- **兼容性**：发布时最新两个稳定主版本的 Chrome/Edge、Android Chrome 和 iOS Safari；Linux 服务器仅需 HTTPS 静态托管。

## 失败行为

- 方向或边界置信度不足时不猜测，不裁掉题面，并提供手动旋转或四角调整。
- HEIC 解码器加载失败时提示具体页面失败，其他 JPG/PNG 页面继续处理。
- 页面取消后可重试；导出只包含已完成页面，并在存在未完成页面时要求确认。
- 刷新恢复数据不完整时将页面重新排队或标记失败，不静默生成缺页 PDF。
- 透明图片先合成白色背景；擦除写入白色，恢复从增强基线找回原像素。

## 验收标准

| ID | 标准 |
| --- | --- |
| AC-1 | 20 张合法图片可按序处理、调整顺序并导出 20 页 A4 竖版 PDF。 |
| AC-2 | 四张授权干净样张和方向变体正确转正，或在低置信度时安全回退。 |
| AC-3 | 可信裁边平均四角归一化误差不超过 0.04；可疑裁边保留整图。 |
| AC-4 | 增强结果为灰度，关键印刷区域相对增强基线零自动删除。 |
| AC-5 | 桌面和手机均可平移、缩放、擦除、恢复、撤销、重做和调整边界，页面无横向溢出。 |
| AC-6 | v2 任务不恢复旧自动擦除图；v3 任务刷新后保留页面顺序和手工笔画。 |
| AC-7 | `lint`、`typecheck`、单测、构建、桌面/移动 E2E、模型校验和样张评测全部通过。 |

## 假设

- 用户对样张和导出材料拥有处理与再分发权限。
- 当前方向模型继续用于生产；低置信度页面由人工兜底。
- 授权 `clean` / `written` / `mask` 样张继续保留为研究资产，但 `mask` 不参与当前生产验收。
