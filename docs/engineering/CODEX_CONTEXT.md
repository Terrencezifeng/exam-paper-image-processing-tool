# Codex 任务上下文

最后更新：2026-08-11（MVP 实现与主流程验证后）

## 目标与验收标准

- 目标：依据 `docs/requirements/worksheet-digitization-mvp.md` 从零实现试卷图片电子化桌面 Web MVP。
- 完成条件：支持最多 20 张图片的导入、页面管理、几何校正、文字增强、黑/蓝/红手写与浅色水印智能擦除建议、人工补修、临时恢复和 A4 PDF 导出，并通过项目质量门禁。

## 范围与非目标

- 包含：无需登录的 Chrome/Edge 桌面应用，浏览器本地处理和存储。
- 不包含：OCR、题库、登录、云同步、移动端、小程序、部署到生产环境。

## 决策与假设

| 主题 | 决策或假设 | 理由 | 重新评估条件 |
| --- | --- | --- | --- |
| 产品范围 | 以 PRD 为唯一需求基线 | 已由用户确认 | 用户更新 PRD |
| 产品名称 | 显示名为 `Exam Paper Image Processing Tool`，npm 包名为 `exam-paper-image-processing-tool` | 使用英文工程名称，同时保留中文操作界面 | 用户再次调整品牌 |
| 数据边界 | 图片不上传，任务仅保存在浏览器本地 | 满足隐私与无账号要求 | 用户批准云端推理 |
| 黑色手写 | 作为智能擦除核心场景，不能只按颜色识别 | 黑色手写在真实试卷中常见 | 样张评估显示需更换方案 |
| 验收素材 | 用户后续提供 8–12 张授权样张 | 真实效果需针对性回归 | 样张到位 |

## 阻塞项与残余风险

- 真实样张尚未提供，因此最终擦除准确率验收暂不可执行。
