# Codex 任务上下文

最后更新：2026-08-18

## 当前目标

- 生产功能聚焦于方向、边界、透视、灰度增强、跨端手动补修和 A4 PDF。
- 不使用自动手写识别、自动擦除、待复核遮罩或外部 OCR API。
- 支持桌面 Chrome/Edge、Android Chrome 与 iOS Safari；Linux 服务器仅静态托管。

## 已实现决策

- PaddleOCR `PP-LCNet_x1_0_doc_ori` 四方向模型在共享 Worker 中运行，WebGPU 失败回退 WASM，双阈值或纵向纸张合理性不通过时不自动旋转。
- 保守纸张边界检测低置信度保留整图；透视重采样使用双线性插值。
- 输出提供逐页及任务级柔和、清晰和高对比三档灰度增强，不使用硬二值化；切换时锁定几何并保留手工编辑，批量档位也作为后续上传默认值。
- 低置信度方向/边界写入页面级复核原因；左栏标记、显式确认和导出前汇总共同防止遗漏，确认状态随任务保存。
- HEIC/HEIF 优先原生解码，失败时按需加载 CSP 兼容的 `heic-to` 本地解码器。
- 编辑器支持移动、滚轮/双指缩放、白色擦除、增强基线恢复、撤销和重做。
- IndexedDB v4 保存逐页增强档位；v2 使用 `enhanced` 作为擦除前基线，v2/v3 迁移为 `soft`。
- 生产模型清单只包含方向模型；手写权重和训练折保留在 `tools/model/artifacts/`。
- PDF 固定 A4 竖版灰度，保留质量和页边距选项。

## 验证重点

1. 四组授权样张的方向、四角误差、灰度和关键印刷零自动删除。
2. 桌面、Pixel 和 iPhone/WebKit 视口的缩放、擦除、撤销、排序、批量增强、复核提示和导出。
3. HEIC 实机解码、12 MP 首图时间、20 页内存、实体打印和 Linux HTTPS 部署。
