# Exam Paper Image Processing Tool

面向教师的试卷图片电子化桌面 Web 工具。图片处理、临时保存和 PDF 生成均在浏览器本地完成，无需注册登录。

## 当前能力

- 一次导入最多 20 张 JPG、PNG 或 WebP 图片，单张最大 20 MB、4000 万像素。
- 自动检测纸张边界并进行透视校正，也可拖动四角手动修正。
- 纸张增白、阴影抑制、印刷文字增强和彩色/黑白模式。
- 基于颜色、笔画连通和版面密度特征生成黑、蓝、红手写及浅色水印擦除建议。
- 处理前后对比、局部复核框、橡皮擦、恢复笔、撤销与重做。
- 页面拖拽/按钮排序、旋转、删除、失败隔离、取消和重试。
- A4 PDF 预览，支持三档清晰度、彩色/黑白和页边距设置。
- IndexedDB 临时恢复；任务超过 24 小时未活动后过期，也可主动清空。

完整产品范围和验收标准见 [试卷图片电子化 MVP 需求](docs/requirements/worksheet-digitization-mvp.md)。

## 本地开发

前置条件：Node.js 24+、npm 11+，桌面 Chrome 或 Edge。

```bash
npm install
npm run dev
```

开发服务器会在终端显示本地地址。生产构建：

```bash
npm run build
```

## 质量检查

```bash
npm run lint
npm run typecheck
npm test
npm run e2e
```

首次运行 E2E 前需要安装测试浏览器：

```bash
npx playwright install chromium
```

这条命令会下载一份由 Playwright 管理的隔离 Chromium，用于自动执行“打开页面、上传图片、点击导出”等端到端测试。它只属于开发和 CI 测试环境：

- 本地开发只需首次安装一次；Playwright 升级后可能需要重新安装。
- 正式部署不需要运行该命令，也不需要把 Chromium 上传到服务器。
- 最终用户直接使用自己电脑上的 Chrome 或 Edge。
- 如果部署流水线需要在发布前运行 E2E，则由 CI 环境执行该命令。

## 后端与数据库

当前 MVP 不需要业务后端或服务端数据库。应用可作为静态网站部署，核心工作全部在浏览器内完成：

- Canvas 负责图片校正、增强和擦除。
- IndexedDB 是浏览器本地数据库，用于临时恢复任务，不会跨设备同步。
- PDF 在浏览器中生成并直接下载。
- 服务器只需要托管 `npm run build` 生成的 `dist/` 静态文件。

当项目增加以下能力时，再引入后端和服务端数据库会更合适：

- 教师账号、历史试卷、跨设备同步或多人协作。
- 分享链接、二维码、班级分发或集中打印。
- 使用服务器 GPU 运行更高精度的手写分割模型。
- 运营后台、使用配额、付费、审计日志或集中故障监控。

建议先用真实样张验证本地智能擦除效果。如果浏览器模型无法达到黑色手写的验收指标，再新增临时推理后端；数据库仍可等账号和历史记录需求出现后再加入。

## 架构概览

- `src/App.tsx`：批量任务、页面编辑、失败恢复和导出工作流。
- `src/lib/image-processing.ts`：解码、纸张检测、透视变换、增强、智能擦除基线和手动遮罩渲染。
- `src/lib/storage.ts`：浏览器本地任务持久化与 24 小时过期策略。
- `src/lib/pdf.ts`：按需加载的 A4 PDF 生成器和安全文件名处理。
- `src/types.ts`：页面状态、擦除笔画、复核区域和导出配置的数据模型。

图像管线按“解码 → 几何校正 → 增强 → 智能擦除 → 人工遮罩 → PDF”分层，后续可以替换智能擦除阶段，而无需改变页面编辑和本地任务模型。

## 隐私与安全

- 用户图片不会上传到服务器，也不进入远程日志。
- 文件在解码前校验 MIME 类型、文件大小，解码后校验像素数量。
- 源图和处理结果只存入当前浏览器的 IndexedDB；主动清空或 24 小时过期后删除。
- 生成 PDF 时会规范化下载文件名，避免路径和平台控制字符。
- 应仅处理和分发已获授权的试卷材料。

## 已知限制

- 当前智能擦除是浏览器本地启发式基线，不是已针对真实试卷训练的专用分割模型。它会把疑似影响印刷内容的区域标为待复核，但尚未证明达到 PRD 中黑色手写 80% 自动擦除、90% 自动擦除或正确标记的指标。
- 最终擦除质量验收需要 8–12 张授权样张，其中至少 4 张包含黑色手写。模型或权重接入前必须核验分发许可证和浏览器性能。
- 图像处理目前运行在主线程；高分辨率页面会先缩放到最长边 2400 像素，但处理期间仍可能出现短暂交互停顿。
- 初版不包含 OCR、可搜索 PDF、Word 导出、账号、云同步、手机浏览器或 HEIC/HEIF 输入。
- 支持发布时最新两个稳定主版本的桌面 Chrome 和 Edge。
